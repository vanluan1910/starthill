# QR Code Design

## Goal

Add a static QR code asset for the deployed project URL `https://starthill.vercel.app/`.

## Scope

- Create a QR code that encodes `https://starthill.vercel.app/`.
- Store the generated files in `public/`.
- Provide both `png` and `svg` formats.
- Use the asset name `qr-starthill` for consistency with the existing public QR assets.

## Approach

- Use static generated assets instead of a React QR library.
- Keep the current app code unchanged unless a later task asks to display the QR in the UI.
- Re-generate the assets if the deployment URL changes in the future.

## Output

- `public/qr-starthill.png`
- `public/qr-starthill.svg`

## Verification

- Confirm both files exist in `public/`.
- Confirm the SVG and PNG render as QR images.
- If generated by CLI, verify the encoded URL matches `https://starthill.vercel.app/`.
